# GPT Image 2 — Copy-Paste Templates

Fill the `<...>` slots. Keep the `scene → subject → details → text → constraints`
order. Pick a size/quality from `parameters.md`.

## 1. Social media post (feed)

```
Intended use: <platform> feed post, square.
Scene: <setting / background color / mood>, <lighting>.
Subject: <main object or person>, <framing>, <pose/gaze>.
Key details: <materials, colors, medium>; clean, on-brand, uncluttered.
Text: "<headline>" — <font style>, <placement>, <color>.
Constraints: leave safe margins for cropping, no watermark.
Suggested: size 1024x1024, quality medium.
```

## 2. Ad creative (write as a creative brief)

```
Brand: <name> — <one-line positioning>.
Audience: <who> who care about <value>.
Vibe: <3 adjectives>.
Scene: <environment that signals the value>.
Subject: <hero product/person>, <how it's presented>.
Text: "<offer/CTA>" — bold, high-contrast, lower third.
Constraints: photoreal, no clutter, strong negative space for logo overlay.
Suggested: size 1024x1536 (story) or 1536x1024 (banner), quality high.
```

## 3. Logo / brand mark

```
Design a clean, original logo mark for <brand>, a <industry> brand whose
personality is <adjectives>. Strong simple shape, balanced negative space,
scalable to a favicon. Medium: flat vector. Single accent color <hex> on
<background>. No photographic elements, no gradients unless requested.
Suggested: size 1024x1024, quality high.
```

## 4. UI mockup (product that "already exists")

```
A high-fidelity UI mockup of <product> showing <screen/feature>. Describe it as
a finished product: realistic layout, clear visual hierarchy, consistent spacing,
real interface elements (nav, cards, buttons, charts). Style: <light/dark>,
<accent color hex>, modern, flat. Avoid concept-art or sketch styling.
Suggested: size 1536x1024, quality high.
```

## 5. Infographic / data slide

```
Intended use: infographic, landscape.
Topic: <subject>. Include these exact figures/labels: <list real numbers/labels>.
Layout: clear sections, generous spacing, readable hierarchy, minimal decoration.
Text: render all labels legibly; titles in <font>, body in <font>.
Constraints: no tiny text, nothing that makes the diagram hard to read.
Suggested: size 1536x1024, quality high.
```

## 6. Product photo (photoreal)

```
A professional product photograph of <product> captured as a real photo in the
moment. <lens, e.g. 85mm>, <aperture feel, e.g. shallow depth of field>,
<lighting, e.g. soft diffused studio light>, <background>. Real texture:
<materials, reflections, surface detail>. <Framing>.
Constraints: photorealistic, no watermark, no extra props.
Suggested: size 1024x1536, quality high.
```

## 7. Edit an existing asset (preserve identity)

```
Edit the attached image. Change only: <the single change>.
Keep everything else the same — preserve <subject identity / pose / layout /
geometry / lighting / background>. Match original lighting and shadows.
(Repeat this preserve-list on every follow-up edit.)
```
