# Nano Banana — Copy-Paste Templates

Fill the `[...]` slots. Prefer full narrative sentences. For editing templates,
attach the reference image and keep the **Preserve** line.

## 1. Product photography

```
A photorealistic close-up of [OBJECT] [held by a hand / on a surface]. The
[MATERIAL] features [DETAILS: texture, finish, color]. Background: softly blurred
[SETTING], [LIGHTING, e.g. natural morning light]. [ASPECT / COMPOSITION].
```

## 2. Style transformation (from a reference)

```
Transform [REFERENCE IMAGE] into [STYLE]: [DETAILS about composition, lighting,
material properties]. Preserve [what to keep from the source]. [Color palette / hex].
```

## 3. Character / avatar creation

```
Create a [STYLE] character based on [REFERENCE IMAGE], accurately preserving
[SPECIFIC FEATURES: face, hairstyle, outfit], rendered as [MEDIUM: vinyl figure /
3D / illustration], with [LIGHTING / ATMOSPHERE].
```

## 4. Voxel / 3D icon

```
Transform [REFERENCE] into a voxel 3D-icon style. Clean studio lighting, soft
shadows, [BACKGROUND color/hex], centered, [RENDER SETTINGS / resolution].
```

## 5. Fake-UI / social mockup

```
A realistic [PLATFORM] post UI showing [CONTENT]. Include authentic UI elements:
[avatar, username, timestamp, like/share icons]. Post text: "[TEXT]". Image area:
[describe attached/generated image]. Crisp, platform-accurate styling.
```

## 6. Multi-image blend

```
Combine the attached images: place [SUBJECT from image 1] into [SCENE from image
2]. [SUBJECT] is in the foreground, occluding [ELEMENT]. Match lighting so shadows
and color temperature are consistent across both. [Mood / final look].
```

## 7. Identity-preserving edit

```
Using the attached photo, change only [THE SINGLE CHANGE].
Accurately preserve the person's face, hairstyle, pose, body shape, and the
background. Match the original lighting and shadows.
```

## 8. JSON-spec generation (complex / brand-consistent)

```
Generate an image from this spec:
{
  "subject": "[SUBJECT]",
  "material": "[MATERIAL/FINISH]",
  "lighting": "[DIRECTION + QUALITY]",
  "color_scheme": ["#RRGGBB", "#RRGGBB"],
  "background": "[BACKGROUND]",
  "text": { "content": "[TEXT]", "placement": "[WHERE]", "style": "[FONT]" }
}
```
