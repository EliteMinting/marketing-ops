# Nano Banana — Use-Case Categories

Distilled from `JimmyLv/awesome-nano-banana` (8.8k★ community collection of
gemini-2.5-flash-image cases). Each category lists what the prompt usually needs.

## Character / personification

Chibi figures, matryoshka dolls, mascots, custom anime/collectible figures.
- **Needs:** reference image of the subject, target style, "preserve facial
  features", desired material (vinyl, plush, resin), pose.

## Product design

Keychains, planters, keycaps, enamel pins, rugs, cushions, necklaces.
- **Needs:** the object, exact material/finish, color palette (hex), background,
  product-photo lighting.

## 3D miniatures & dioramas

Buildings, landscapes, snow globes, tilt-shift scenes.
- **Needs:** "isometric angle", "tilt-shift lens effect", "miniature perspective",
  scene contents, lighting.

## Art styles & illustrations

Vector art, pixel icons, paper craft, silhouettes, double exposure.
- **Needs:** named style, subject, color scheme, level of detail, medium.

## Photography & realistic rendering

Fashion covers, glass retexturing, product photography, fake tweets/posts.
- **Needs:** photography language (lens, lighting, framing), real texture,
  background; for retexturing use a JSON material spec.

## Interactive & composite effects

Breaking through frames, pop-out effects, perspective illusions.
- **Needs:** clear description of what breaks the plane, occlusion order,
  consistent lighting between layers.

## Creative transformations

Map → treasure map, cloud art, silk universe, popsicle worlds, etc.
- **Needs:** source reference, target concept, composition/material details,
  what to preserve from the source.

## Marketing mapping (for this repo)

| Marketing asset | Category | Quick recipe |
|-----------------|----------|--------------|
| Instagram/feed post | Photography / art styles | narrative scene + brand palette + text line |
| Product shot | Product design / photography | object + material + studio light + clean BG |
| Mascot / avatar | Character | reference + style + "preserve features" |
| Campaign hero (4K) | Photography (use **Pro**) | full narrative + 16:9 + 4K |
| Social mockup (fake UI) | Composite / fake media | platform UI details + timestamps + text |
