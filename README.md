# نظام تنظيم قسم التسويق (موقع ويب)

موقع ثابت (HTML/CSS/JS) عربي RTL لإدارة عمل قسم التسويق: لوحة تحكم، خطة محتوى، مهام، فريق، وقوائم قابلة للتعديل — بتصميم حديث أنيق.

## التشغيل
- **محلياً:** افتح `index.html` بالنقر المزدوج (يعمل دون إنترنت).
- **على الويب:** منشور عبر GitHub Pages (رابط دائم).

## المزايا
- لوحة تحكم تتحدّث تلقائياً (مؤشرات + دوائر إنجاز + اتجاه المحتوى + عبء العمل + توزيع الحالات).
- جداول قابلة للتعديل داخل الصفحة (إضافة/حذف صفوف، قوائم منسدلة، حالات ملوّنة).
- ربط المهام بالمحتوى، واحتساب التأخير وأعمدة عبء الفريق تلقائياً.
- حفظ تلقائي في المتصفح (localStorage) + استيراد/تصدير JSON.

## ملاحظة عن البيانات
البيانات محفوظة في متصفحك على هذا الجهاز فقط. للمشاركة أو النسخ الاحتياطي أو النقل بين الأجهزة استخدم **تصدير/استيراد JSON** من شريط الأعلى أو صفحة الإعدادات.

## البنية
```
index.html · css/styles.css · js/{data,state,compute,charts,tables,views,app}.js · assets/favicon.svg
```
لا يحتاج أي build أو خادم — ملفات ثابتة فقط.
