# إعادة تصميم الواجهة — مستوحاة من أسلوب «Skillset» (محايد فحمي + لمسة أزرق)

> وثيقة تصميم مرجعية. الهدف: رفع الموقع لمستوى لوحات SaaS الاحترافية الحديثة —
> نتعلّم من المرجع ونوظّفه (بدون نسخ بياناته). لا نشر حتى التحقّق بالقطات الشاشة وموافقة المالك.

## القرارات المعتمدة
- **الطابع اللوني:** أساس محايد فحمي/رمادي نظيف + عنصر «مميّز» داكن (بطاقة KPI/حالات نشطة) + **لمسة أزرق خفيفة** للروابط/التركيز/المؤشر النشط.
- **مؤشرات الفرق:** فروقات «مقارنة بالشهر الماضي» **حقيقية** عبر لقطات شهرية تُحفظ محلياً.
- **النطاق:** نظام التصميم بالكامل + لوحة تحكم جديدة، وكل الواجهات العشر ترث المظهر.

## ما نتعلّمه من المرجع (وكيف نوظّفه)
| عنصر المرجع | التوظيف عندنا |
|---|---|
| خلفية رمادية فاتحة + بطاقات بيضاء بزوايا كبيرة وظلال خفيفة جداً + حدود شعرة | تحديث الـ tokens (سطوح/حدود/ظلال/أقطار) |
| الشعار أعلى الشريط الجانبي، والعنوان في الأعلى | نقل الشعار للشريط الجانبي؛ الشريط العلوي = عنوان الصفحة + بحث + جرس + أفاتار |
| بطاقة KPI «مميّزة» داكنة + بقية بيضاء، مع مؤشر اتجاه ▲/▼ ونسبة | بطاقات KPI جديدة: أولى داكنة، والبقية بيضاء، بفرق شهري حقيقي |
| تبويب فترات مجزّأ (Day/Week/Month/Year) | مكوّن `.segmented` لإعادة الاستخدام (يُستخدم لتبديل عرض حقيقي: أسبوعي/تراكمي) |
| أعمدة رسم بزوايا دائرية وأحدها مميّز | دالة جديدة `M.vbars` (أعمدة رأسية دائرية، فحمية، عمود مميّز) |
| دونات «نمو المجتمع 65%» | إعادة تصميم `M.donut` كحلقة سميكة بنسبة في المنتصف |
| شريط أيام مع تمييز اليوم | ودجت «هذا الأسبوع» يعرض المهام المستحقة لكل يوم مع تمييز اليوم |
| جدول بأفاتار وحالة بحبّة | جداول أنظف + أفاتار أحرف للمسؤول + حبوب الحالة الحالية |
| بطاقة ترقية في الجانب | بطاقة CTA لطيفة: «المساعد الذكي» (اختصار) بدل الترقية |

## نظام الألوان (Tokens)
**فاتح:** `--bg:#F1F2F4` · `--surface:#FFFFFF` · `--surface-2:#F6F7F9` · `--surface-3:#ECEEF1`
· نص: `--ink:#14161B` `--text:#3A4150` `--muted:#767E8C` `--faint:#A6ACB6`
· **مميّز داكن:** `--feature:#181A20` `--feature-2:#22252E` `--feature-text:#FFFFFF` `--feature-muted:#A8AEBA`
· أزرق: `--primary:#2F6BF0` `--primary-600:#1E55D6` `--primary-50:#EAF1FE` `--ring:rgba(47,107,240,.30)`
· حدود: `--border:#E8EAEE` `--border-strong:#DBDEE4`
· فروق: `--up:#1E9E5A` `--down:#E5484D`
· نُبقي ألوان الحالات (مع ضبط طفيف) للحبوب والرسوم.
**داكن:** فحمي أعمق (`--bg:#0E1014`، `--surface:#16181E`، `--feature:#000`/`#0A0B0D`)، أزرق أفتح، حدود داكنة.

**الطباعة/الأقطار/الظلال:** أقطار أكبر (بطاقات 18–20px)، ظلال ناعمة جداً + اعتماد على الحدود الشعرة، مسافات أوسع.

## المكوّنات (نعيد استخدام نفس الأصناف قدر الإمكان)
1. **الشريط العلوي:** يسار = عنوان الصفحة الديناميكي (يتزامن مع `M.showView`)؛ يمين = بحث (pill) + جرس (يعرض عدد التنبيهات، نقره → المهام) + تبديل الثيم + PDF + أفاتار.
2. **الشريط الجانبي:** ترويسة بالشعار + اسم النظام؛ عناصر تنقّل بحالة نشطة بحبّة ناعمة + مؤشر؛ بطاقة CTA للمساعد الذكي بالأسفل.
3. **`.segmented`:** مكوّن تبويب مجزّأ (الفعّال داكن) — يُستخدم في لوحة التحكم لتبديل عرض الاتجاه (أسبوعي/تراكمي) فعلياً.
4. **بطاقات KPI:** `.kpi--feature` (داكنة) للأولى؛ صف فرق `.kpi-delta.up/.down` (سهم + نسبة + «عن الشهر الماضي») من فروقات حقيقية؛ تبقى `.kpi--*` للبقية.
5. **الرسوم:** `M.vbars` جديدة (أعمدة رأسية دائرية، عمود الحالي/الأعلى مميّز)؛ `M.donut` حلقة أسمك؛ `M.hbars` تبقى للعبء.
6. **ودجت «هذا الأسبوع»:** شريط ٧ أيام، تمييز اليوم، وعدد المهام المستحقة/يوم (من المهام الفعلية).
7. **الجداول:** أفاتار أحرف للمسؤول، رؤوس أنظف، حبوب الحالة. **الشريط السفلي** للجوال يُصقل بنفس اللغة.

## الفروقات الحقيقية (لقطات شهرية)
- في `js/state.js`: عند الحفظ نُحدّث `M.state.settings.history[YYYY-MM]` بلقطة من `M.kpis()` للشهر الحالي (تُخزَّن ضمن البيانات فتُصدَّر مع JSON).
- في `js/compute.js`: `M.kpiDeltas()` تقارن الشهر الحالي بأحدث شهر سابق متوفّر؛ إن لا يوجد سابق → بلا نسبة (صادق).
- في `js/data.js`: نضيف لقطة «شهر سابق» في البيانات التجريبية (example) ليظهر العرض بفروقات منطقية فوراً.
- migration في `state.js` يضمن وجود `settings.history`.

## الملفات المتأثّرة
- `css/styles.css` — تحديث Tokens شامل + مكوّنات جديدة (`.segmented`, `.kpi--feature`, `.kpi-delta`, `.weekstrip`, `.avatar`, ترويسة الشريط الجانبي، بطاقة CTA) + مواءمة الوضع الليلي/الطباعة/الجوال.
- `index.html` — إعادة هيكلة الشريط العلوي (عنوان + بحث + جرس + أفاتار) والشريط الجانبي (شعار + CTA).
- `js/views.js` — إعادة بناء `M.views.dashboard`؛ تزامن عنوان الصفحة في `M.showView`؛ إضافة الأفاتار في جداول المحتوى/المهام/الفريق (دالة مساعدة `avatar()`).
- `js/charts.js` — `M.vbars` + صقل `M.donut`.
- `js/compute.js` — `M.kpiDeltas()` (+ إبقاء البقية).
- `js/state.js` + `js/data.js` — لقطات التاريخ + migration + بذرة شهر سابق.
- `js/app.js` — عنصر عنوان الصفحة + الجرس (تنبيهات) + الأفاتار.
- بلا تغيير منطقي في `tables.js`/`ai.js`.
